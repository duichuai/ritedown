## 缺陷修复记录

| 版本 | 问题 | 处理 |
|---|---|---|
| 2.1.1 | Tauri/WebView2 下 `window.confirm` 不渲染 UI，关闭窗口会静默退出 | 改用 dialog 插件 `ask()`，Web 端回退 `confirm` |
| 2.1.1 | 插件开关只写 localStorage，需重启才生效 | 面板与管线共享同一个响应式禁用列表 |
| 2.2.0 | v2.1.1 安装包内仍是 2.1.0 的 bundle 版本号 | 打包版本改为跟随 release tag |
| 2.1.0 | 默认文档与样式引用了 GFM Alerts，但扩展从未启用 | 接入预览管线 |
